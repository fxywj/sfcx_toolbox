# 接入真实数据（D 线项目）

工具箱本身不绑定本项目；下面是把它接到 `D_SFC_VariabilityAxis` 现有输出上的最短路径。

## 一、项目里已经有的东西

| 文件 | 内容 | 形状 |
|---|---|---|
| `02_执行分析/STEP03_变异性谱/_cache/zA.npy` | 所有被试的 SC 边向量 | (1022, 64620) float32 |
| `02_执行分析/STEP03_变异性谱/_cache/f_Rest.npy` | 所有被试的 FC 边向量（Rest） | (1022, 64620) float32 |
| `.../STEP03_变异性谱/outputs/S03b_1_边变异性_Rest.npz` | `V_sfc / V_fc / V_sc / gmean / hier / same_net / iu_i / iv_j` | 每条边一个值 |
| `.../_cache/group.npz` | `SCsum / FCsum / n_sc / n_fc` | (360, 360) |

64,620 = 360×359/2，即 Glasser-360 的上三角。

## 二、需要补的两个向量

工具箱要求每个脑区一个 `networks` 标签和一个 `hierarchy` 值：

- `hierarchy`：用 Yeo-7 的层级序（1 = Visual → 7 = DefaultMode），项目里已有等价物（`hier` 是边级版本，取任一端点的区域级标签即可还原）；
- `networks`：每个 Glasser 脑区的 Yeo-7 归属。若项目里有 `glasser_yeo7.csv` 之类的映射表，直接读；没有的话，可从 `S03b_*.npz` 的 `same_net` 反推不唯一，建议用标准映射表（Glasser 360 → Yeo-7 的公开对照）。

## 三、组装一个 npz

```python
import numpy as np
from sfcx import Cohort, demo

N, P = 1022, 360
iu, iv = np.triu_indices(P, k=1)

sc = np.load("zA.npy")                # (1022, 64620)
fc = np.load("f_Rest.npy")            # (1022, 64620)
networks = np.load("glasser_yeo7.npy")     # (360,) int
hierarchy = np.load("glasser_hier.npy")    # (360,) float, 1..7

np.savez_compressed(
    "dline_rest.npz",
    sc=sc, fc=fc, iu_i=iu.astype(np.int32), iv_j=iv.astype(np.int32),
    networks=networks, hierarchy=hierarchy, n_nodes=P,
)
```

然后：

```bash
sfcx run   --npz dline_rest.npz --preset default --out dline_out --perm 2000
sfcx sweep --npz dline_rest.npz --out dline_sweep --perm 1000
```

## 四、会复现什么、不会复现什么

| 量 | 能否复现 | 说明 |
|---|---|---|
| `Vij`（边级 SD） | ✅ 直接算 | 与 `S03b` 的 `V_sfc` 同源 |
| `Vnode` | ✅ 直接算 | 由 `Vij` 按脑区取均值 |
| `Vi`（区域级 SD） | ✅ 用 `cohort.regional_coupling()` | 即 c_i = corr(SC_i., FC_i.) |
| 层内/层间 Δ | ✅ | 论文报 0.58–0.68 |
| split-half | ✅ | 论文报 0.996–0.997 |
| 16 个焦点 | 🟡 取决于结构图稀疏度 | 图越密，局部极大越少 |
| 个体斜率与行为 | ✅ 需要把行为向量一并放进 npz | 论文用 NMA-single 模型做增量预测，本工具只做偏相关 |

## 五、真实数据上的注意事项

1. **内存**：两个 (1022, 64620) float32 约 264 MB，放进 `Cohort` 后是同样的量级；矩阵类定义（communicability / mfpt）只在 360×360 上算，不额外占内存。
2. **null 选择**：没有球面坐标时默认走 `msr`；要在真实数据上做严格的 spin，需要补 Glasser-360 的球面质心坐标。
3. **`search_info` 较慢**：360 节点全对最短路径约 12.9 万条，单次运行可接受，扫 8 个定义时建议先跳过它。
4. **`same_net` 不等于 `networks`**：前者是边级布尔，后者是区级标签，别互相替代。
